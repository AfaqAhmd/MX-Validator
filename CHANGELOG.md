# Changelog

All notable changes to the **Lead List MX Validator** are documented here.

## [1.0.0] - 2024-12-16

### Initial Release

- Upload CSV files with lead lists
- Validate email domains via MX record lookup
- Detect email security gateways (Proofpoint, Mimecast, Barracuda, etc.)
- Identify email providers (Google Workspace, Microsoft 365, etc.)
- Real-time scanning progress with live updates
- Analytics dashboard with charts and insights
- Export results as CSV
- Modern dark theme UI
